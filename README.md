# 20cm 點光源媒體測試

這是一個雙塔點光源 facade 的快速測試頁，用來讓團隊在瀏覽器中確認 20cm 點距下的海浪、圖片與 MP4 動態素材映射效果。

## Live Demo

GitHub Pages 啟用後，可用固定網址測試：

https://iverson777.github.io/tower-light-grid-demo/

## 目前模擬規格

- 單塔：8m x 16.1m
- 窗格配置：8 欄 x 8 層
- 每片 window：100 x 190cm
- 水平白框：10cm，可在介面中開關
- 垂直框：無
- 點距：20cm
- 燈點直徑：4cm
- 單塔點陣：41 x 81
- 每條垂直燈串：81 顆
- 每塔垂直燈串：41 條
- 單塔總燈點：3,321 顆
- 雙塔總燈點：6,642 顆

## 使用方式

1. 開啟 live demo 或本地 `tower_light_grid_demo.html`。
2. 測試生物或正式素材時，保持「Fixture 精準」開啟。
3. 亮度 / Dimmer 建議先維持 1.0，再依現場亮度需求微調。
4. 現場是自發光點光源，肉眼會看到光暈；可用「現場光暈」調整暈開程度。
5. 使用預設的藍色潮汐海浪確認整體亮暗節奏。
6. 上傳 JPG、PNG 或 MP4，測試平面生物圖、海浪動畫或其他動態素材。
7. 用「映射」切換填滿裁切、完整留黑、拉伸填滿，並和 MadMapper 中的素材映射方式保持一致。
8. 用「橫白框」開關確認白色水平框線對畫面的影響。

## Fixture 精準模式

Fixture 精準模式是給 MadMapper fixture mapping 前的素材檢查用。此模式會：

- 將上傳素材取樣成 41 寬 x 81 高。
- 每一個取樣 pixel 對應一顆燈點。
- 關閉自動對比增強，避免生物輪廓被 demo 人為強化。
- 以亮度 / Dimmer 作為全局輸出亮度，1.0 代表不額外放大。
- 保留獨立的「現場光暈」預覽。光暈只影響肉眼觀看感，不改變每顆燈的取樣顏色。

如果關閉 Fixture 精準，畫面會進入較漂亮的舞台預覽模式：保留微幅對比增強與光暈，適合看遠距離氣氛，但不建議當作生物可讀性的最終判斷。

## 關於現場光暈

現場點光源是自發光，肉眼看一定會有暈開、疊光與環境反射。這個 demo 的「現場光暈」是視覺預估，不是 fixture 資料本身。建議測試時看兩次：

- 光暈調低或歸零：確認 41 x 81 原始點位是否真的讀得出輪廓。
- 光暈調到中等：確認比較接近現場觀看時的自發光連續感。
- 上傳 JPG / PNG / MP4 時，畫面基底會切成黑色。若素材本身是黑底，黑色區域會以熄燈黑呈現。

## 給視覺素材的建議

- 最好直接用 41 x 81 的低解析畫面思考生物，而不是先做高解析細節再期待燈點保留。
- 魚或海洋生物要用大輪廓、厚形狀、高對比、慢速擺動。
- 避免太細的線、太小的魚、密集紋理、很薄的透明漸層。
- 若用高解析影片，MadMapper 與 demo 的裁切方式要一致，否則現場比例會不同。
- 如果要最接近 fixture，建議輸出一版 41 x 81 或等比例放大的測試影片，再讓 MadMapper fixture 對應到同一個畫面比例。

## 判讀提醒

這個 demo 會把素材取樣成 41 x 81 的低解析點陣，再顯示到塔面燈點上。請把它當成實際 20cm 點光源的初步視覺檢查：細節會被抽掉，真正保留下來的是大輪廓、亮暗節奏、移動方向與整體氣氛。

若要測試海洋生物，建議使用大輪廓、低細節、高對比的圖像或影片。過細的紋理、太小的魚、太薄的線條，在 41 x 81 點陣上會很容易消失。
